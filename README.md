# Сервис сокращения ссылок 

Консольное приложение на Java (версия 17+) для генерации коротких веб-ссылок с поддержкой лимита переходов, автоматическим контролем времени жизни, разграничением прав доступа по UUID и чтением настроек из внешнего файла конфигурации.

## Архитектура проекта

Проект спроектирован по принципу разделения ответственности, где каждый компонент вынесен в отдельный файл:

* **`ShortLinkApp.java`** — точка входа (`main`), консольный интерфейс для взаимодействия с пользователем (`Scanner`) и запуск фонового планировщика очистки (`ScheduledExecutorService`).
* **`LinkService.java`** — основной сервис бизнес-логики. Отвечает за генерацию уникальных кодов (используется безопасный алфавит без визуально похожих символов `0`, `O`, `1`, `I`, `l`), валидацию URL, учет переходов, проверку прав владельца и отправку уведомлений.
* **`ShortLink.java`** — модель данных короткой ссылки. Хранит исходный адрес, токен создателя, время создания (`Instant`), срок жизни (`Duration`) и потокобезопасные счетчики кликов (`AtomicInteger`).
* **`AppConfig.java`** — модуль загрузки параметров из файла `config.properties` (длина кода, срок жизни в часах, лимиты кликов, период очистки) с безопасным откатом к значениям по умолчанию.
* **`ShortLinkAppTest.java`** — набор из 19 модульных тестов (JUnit 5), проверяющих корректность создания ссылок, лимиты, истечение срока жизни, права доступа и уведомления.

## Настройка конфигурации (`config.properties`)

Параметры работы сервиса задаются в файле `config.properties` в корне проекта (при отсутствии файла применяются стандартные значения):

```properties
app.code.length=6
app.ttl.hours=24
app.cleanup.period.seconds=30
app.default.click.limit=100
app.max.click.limit=10000
```

## Сборка и запуск

1. Убедитесь, что установлена **Java 17** или выше:
   ```bash
   java -version
   ```
2. Скомпилируйте все исходные файлы проекта из корневой директории:
   ```bash
   javac AppConfig.java ShortLink.java LinkService.java ShortLinkApp.java
   ```
3. Запустите приложение:
   ```bash
   java ShortLinkApp
   ```

## Руководство пользователя

После запуска программа предложит ввести существующий `UUID` или нажать `Enter` для автоматической генерации нового профиля. Управление осуществляется через консольное меню:

* **`1`** — **Создать короткую ссылку:** введите исходный адрес (`http://` или `https://`) и укажите лимит переходов. Сервис вернет ссылку вида `clck.ru/XXXXXX`.
* **`2`** — **Перейти по ссылке:** введите короткую ссылку или её 6-значный код. Если лимит не исчерпан и срок жизни не истек, страница откроется в браузере по умолчанию.
* **`3`** — **Мои ссылки:** отображает список всех активных ссылок текущего пользователя со статистикой переходов.
* **`4`** — **Изменить лимит переходов:** позволяет владельцу обновить максимальное число кликов для своей ссылки.
* **`5`** — **Удалить ссылку:** досрочное удаление ссылки её создателем.
* **`6`** — **Уведомления:** просмотр системных оповещений об исчерпании лимита переходов или удалении ссылок по истечении срока жизни.
* **`0`** или **`выход`** — корректное завершение работы приложения и остановка фоновых потоков.

## Тестирование

Бизнес-логика покрыта модульными тестами на **JUnit 5** в классе `ShortLinkAppTest`:

* **Проверка уникальности и валидации:** генерация разных кодов для разных пользователей на один URL, отсеивание пустых или некорректных адресов.
* **Контроль лимитов и времени жизни:** блокировка ссылки при достижении порога кликов, автоматическое удаление после истечения заданного периода (`Duration`).
* **Безопасность и уведомления:** запрет на редактирование или удаление чужих ссылок, проверка доставки уведомлений владельцу.
